# Beauty Saloon su Sites

Sito pubblicato: https://beauty-saloon.stefanobarberi76.chatgpt.site

La cartella `dist/` contiene la versione pubblicata su Sites, inclusa la fotografia locale. `.openai/hosting.json` identifica il progetto Sites esistente.

Per visualizzare questa versione in locale:

```sh
python3 -m http.server 8000 --directory dist
```

Aprire http://localhost:8000.

I file alla radice preesistenti sono una versione distinta e sono stati conservati.

GitHub conserva una copia del codice. Non è configurata una sincronizzazione automatica o una pubblicazione automatica da GitHub a Sites. Le modifiche devono essere trasferite nel progetto Sites e pubblicate tramite Sites.
