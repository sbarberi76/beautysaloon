# Beauty Saloon

Sito responsive in italiano, realizzato con HTML, CSS e JavaScript senza dipendenze di build.

## Avvio locale

Dalla directory del repository:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

## Personalizzazione

Prima della pubblicazione, confermare servizi e prezzi e aggiungere i contatti reali del salone. Il modulo prepara una richiesta sul dispositivo: non invia dati e non conferma appuntamenti. Per ricevere richieste occorre collegare un servizio di prenotazione o un backend.

Le fotografie vengono caricate da Unsplash e i font da Google Fonts; in assenza di rete sono disponibili font di sistema. Il sito può essere ospitato su qualsiasi servizio di hosting statico.
